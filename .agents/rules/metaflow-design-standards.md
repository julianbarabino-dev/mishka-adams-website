# Metaflow Web Design Standards

Al planificar, maquetar o diseñar sitios web o landing pages en este proyecto:

1. **Estándar Editorial de Alto Impacto:**
   - Inspirarse en estudios boutique de música y cultura como [The Creative Corporation](https://thecreativecorporation.com/) y las referencias del moodboard local.
   - Evitar plantillas o estilos genéricos. Priorizar dirección de arte editorial, tipografías expresivas con contraste de escala, espacios negativos generosos y micro-interacciones sutiles.

2. **Estructura y Multimedia para Artistas:**
   - Diseñar experiencias inmersivas que funcionen como archivos vivos y galerías digitales.
   - Integrar elegantemente reproductores (Spotify, Bandcamp, YouTube), botones interactivos y enlaces a plataformas.

3. **Excelencia Técnica:**
   - HTML5 semántico impecable y jerarquía de encabezados ordenada.
   - Metadatos estructurados (JSON-LD / Schema.org) para músicos, álbumes y clases/talleres.
   - Rendimiento optimizado y accesibilidad WCAG AA.

4. **Cero Emojis en la Interfaz (Zero-Emoji Policy):**
   - Queda estrictamente prohibido el uso de emojis de sistema operativo (ej: 👥, 🎙️, ✦, ♫, 💬, ✉️, etc.) en títulos, textos, badges o botones.
   - Los emojis abaratan la estética editorial. Utilizar exclusivamente iconos SVG vectoriales minimalistas y refinados, o caracteres tipográficos discretos acordes al diseño.
